Presentations

Client decks.

Every HAAVN supply presentation, live and presentable from here. Arrow keys or space to advance, G for the overview, F for fullscreen, ⌘P to export the deck as a PDF.

Adding a presentation A deck is a project record in presentation.html — copy an existing one in the PROJECTS block and change the details. A finished PDF (a document that is already designed) goes in as page images instead: render it to assets/<name>/p-01.jpg and describe the sections with pageSlides(). Then add the row to DECKS at the top of this page.

Filing a document Drop the file into public/haavn-supply/documents/ and add one row to the DOCS block at the top of this page — category, title, one line of description, the filename and its size. It appears on the shelf the moment the site redeploys.
